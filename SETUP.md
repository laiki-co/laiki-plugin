# Connect Laiki

Laiki uses OAuth. Never paste an access token, API key, or password into chat.

## Claude Code

1. Enable the Laiki plugin.
2. Run `/mcp`.
3. Select `plugin:laiki:laiki`.
4. Follow the browser authorization flow.
5. Ask Laiki to list the organizations available to your account.

## ChatGPT and Codex

1. Install Laiki from the plugin source or directory.
2. Select **Connect** when prompted.
3. Follow the browser authorization flow.
4. Start with: `List the Laiki organizations I can access.`

Access remains limited by your Laiki organization membership, role, and MCP
policy. Disconnect Laiki from your AI client to revoke that client's access.
